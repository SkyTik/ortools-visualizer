## Project Overview

Interactive React demo visualizing 7 TSP first solution strategies from Google OR-Tools. Users step through algorithm execution to see how each strategy builds routes.

## Commands

```bash
pnpm dev              # Start dev server (Vite)
pnpm build            # TypeScript compile + Vite build
pnpm lint             # Type check only (tsc --noEmit)
pnpm preview          # Preview production build
pnpm generate-solutions  # Regenerate solution JSON files (requires Python 3 + ortools)
```

## Architecture

### Data Flow
1. **Solution JSON files** (`src/data/solutions/{5-10}/{strategy}.json`) - Pre-computed step-by-step algorithm traces generated by Python script
2. **useTSPDemo hook** (`src/hooks/useTSPDemo.ts`) - Central state management: loads solutions via dynamic import, caches them, handles step navigation
3. **MapCanvas** - SVG visualization rendering nodes, edges, and animation based on current step
4. **AlgorithmPanel** - Displays pseudocode with highlighted current line + step explanation

### Key Types (`src/types/index.ts`)
- `Solution` - Complete algorithm trace with steps array and final route
- `Step` - Single algorithm state: edges drawn, current node, candidates being evaluated, explanation
- `Strategy` - Algorithm metadata and pseudocode

### Component Structure
- `components/map/` - SVG rendering: Node, Edge, PotentialEdge (candidates), RouteAnimator
- `components/controls/` - LocationSelector (5-10 nodes), StrategyTabs (7 algorithms), StepControls
- `components/algorithm/` - Pseudocode display with step highlighting

### Solution Generation
Python script (`scripts/generate_solutions.py`) uses Google OR-Tools to:
1. Run each of 7 strategies on fixed location sets (5-10 nodes)
2. Capture step-by-step state with edges, candidates, explanations
3. Output 42 JSON files (6 counts × 7 strategies)

Locations are fixed in `src/data/locations.ts` - same coordinates for all strategies to enable fair comparison.

## Tech Notes

- Path alias `@/` maps to `src/`
- Tailwind CSS 4 configured via `@tailwindcss/vite` plugin
- Solutions loaded via Vite's dynamic import for code splitting
- Keyboard navigation: Arrow keys for steps, Home/End for first/last
